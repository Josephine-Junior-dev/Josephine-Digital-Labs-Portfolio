# Josephine — Developer Portfolio

A responsive, static portfolio website designed to introduce Josephine and her projects to technical mentors, collaborators, and potential employers.

## Files
- `index.html` — page content and project links
- `style.css` — responsive visual design
- `script.js` — mobile navigation and copy-introduction button

## Publish with Netlify
1. Create a new GitHub repository named `josephine-portfolio` (public).
2. Upload these three files and this README to the repository root.
3. In Netlify, choose **Add new site → Import an existing project** and connect the repository, or use Netlify Drop to deploy the site files.
4. The site is static and does not need a build command. Publish directory: `.`

## Before sharing
- Add a professional contact email or LinkedIn profile if you want mentors to contact you directly.
- Check each project link and make sure it points to the correct source repository.
- The PesaGuard card currently links to the former `Living-Budget` repository for source code. Update that link if its repository has been renamed.
- Only list skills and features you can discuss honestly. Projects are labelled as in progress where appropriate.

No private keys, passwords, or database credentials are included.
